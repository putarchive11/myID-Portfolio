## The app

Kunci Umroh Sendiri is the companion to the Kunci Umroh Mandiri ebook. It can be installed on a phone's home screen like a regular app and still opens without a signal, which matters once you are in the Holy Land.

## Key features

- **Home:** shortcuts to the tools used most often
- **Preparation:** document and packing checklists, a timeline from six months before departure to the day before, an itinerary, an umrah cost calculator, a savings calculator, and riyal-to-rupiah conversion
- **Worship:** the order of the pillars of umrah, guidance on miqat and the intention for ihram, tawaf, sa'i, and tahallul, complete with fully vowelled supplications
- **Me:** activation status in the buyer's name

## Activation codes

So that only buyers can use the app, I built an activation code system in the format KUS-XXXX-XXXX. Codes are checked on the server (a Vercel function with an Upstash Redis database), so the list of codes never reaches the browser. Each code works on up to two devices. An admin page lets me create codes, send them to buyers via WhatsApp, reset devices when a buyer changes phones, and revoke codes when a refund is issued.

## Design details

I replaced emoji icons with consistent line icons, used an Islamic star pattern for the background, and set the supplication text with the mushaf form of sukun so it matches what pilgrims read in the Qur'an.
